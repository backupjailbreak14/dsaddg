# Privacy Policy

**Last Updated:** July 20, 2026

This Privacy Policy explains how the Discord Bot collects, stores, and uses information.

## 1. Information We Collect

The Bot may collect and store the following information when necessary for its functionality:

* Discord User IDs
* Discord Server IDs
* Discord Channel IDs
* Discord Role IDs
* Discord Message IDs (when required for specific features)
* Server configuration data
* Command usage logs
* Game-related data
* Moderation logs
* Award and medal records

The Bot does **not** collect:

* Discord passwords
* Payment information
* Email addresses
* Personal information outside of publicly available Discord account data
* Private Direct Messages unless a feature explicitly requires processing a message sent directly to the Bot

## 2. How We Use Your Data

Collected data is used only to provide the Bot's features, including:

* Server moderation
* Logging
* Role management
* Event management
* Games
* Medal and award systems
* Server configuration
* Command functionality

## 3. Data Storage

Data is stored only as long as necessary for the Bot to function properly. Server administrators may remove data by removing the Bot from their server or requesting deletion where applicable.

## 4. Data Sharing

We do not sell, rent, or share collected data with third parties unless required by law.

## 5. Security

Reasonable measures are taken to protect stored data. However, no system can guarantee absolute security.

## 6. Third-Party Services

The Bot uses Discord's API and may interact with third-party services when enabled by server administrators. Those services have their own privacy policies.

## 7. Your Rights

Server administrators may request the deletion of stored server-specific data where technically possible.

## 8. Changes to this Privacy Policy

This Privacy Policy may be updated at any time. Continued use of the Bot indicates acceptance of any changes.

## 9. Contact

If you have questions regarding this Privacy Policy, please contact the Bot administrators through the official Discord server.
